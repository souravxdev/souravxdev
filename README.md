## About Me

I'm a Frontend Engineer with nearly 3 years of experience building high-performance web applications for a large-scale SaaS platform with **Angular (v14–v20)** and **TypeScript**. My path runs from UI/UX design → frontend engineering → full stack, so I care as much about clean architecture and maintainable code as I do about pixel-perfect UI.

I work daily in a fully remote product team spanning the USA, Europe, India and Albania, and I keep up with modern AI tooling to ship faster without cutting corners.

> 🅰️ **Modernizing Angular codebases**: version upgrades and migrations to standalone components, Signals and Signal Store.   
> 🤖 **AI-assisted engineering**: built an agentic AI orchestration system that automates UI scaffolding, cutting new component build time by 60–70%.

- 🏗️ &nbsp;Building reusable, standalone component libraries from **Figma** designs using **OOP, SOLID and DRY**
- 🔄 &nbsp;Reactive state with **RxJS, Angular Signals, Signal Store and NgRx**
- 📡 &nbsp;Real-time features with **WebSockets + RxJS**, keeping the UI in sync with live data
- 🔐 &nbsp;Secure auth with **JWT, OAuth2**, route guards and functional HTTP interceptors
- ⚡ &nbsp;Performance tuning with **OnPush, lazy-loaded routes, `@defer`** and bundle optimization
- 🧪 &nbsp;End-to-end testing with **Playwright**, plus Jasmine/Karma unit tests
- 🧠 &nbsp;Staying current with **LLMs, RAG and agentic workflows**, and applying them to real developer workflows

**Featured project: Uttirno** (Angular 21 + NestJS 11): an exam-prep platform with a contract-first OpenAPI setup that generates typed Angular API clients from the NestJS backend, a CI-verified guarantee that correct answers never reach the client before submission, and server-side session persistence built to survive power cuts.
